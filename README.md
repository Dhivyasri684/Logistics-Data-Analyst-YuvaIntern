# Logistics Data Analyst Internship - Week 1

## Project
**Strategic Planning and Data Exploration in Logistics**

This repository contains the Week 1 deliverables for a YuvaIntern Logistics Data Analyst Internship.

### Contents
- `Week1_Strategic_Planning_Logistics_Report.docx` - main report submitted to YuvaIntern.
- `week1_logistics_analysis.py` - Python prototype for data exploration and KPI calculation.
- `sample_logistics_data.csv` - small synthetic dataset used only to demonstrate the Week 1 workflow.

### Proposed KPIs
1. On-Time Delivery Rate
2. Average Delivery Delay
3. Average Transportation Distance

### Data Sources / References
- World Bank Logistics Performance Index (LPI): https://datacatalog.worldbank.org/search/dataset/0038649/logistics-performance-index
- World Bank LPI DataBank: https://databank.worldbank.org/reports.aspx?dsid=66&series=LP.LPI.OVRL.XQ
- Data.gov / FEMA Shipment (Delivery): https://catalog.data.gov/dataset/shipment-delivery

### Important note
The CSV in this repository is synthetic and is included for workflow demonstration. It should not be presented as real company data. Week 2 will focus on data collection, cleaning, missing-value handling and normalization before deeper analysis.
