# Logistics Data Analyst Internship

## 📌 Project Overview

This repository contains the complete work completed as part of a
Logistics Data Analyst Internship.

The project focuses on logistics data analysis, data preparation,
exploratory analysis, KPI calculation, visualization, and
data-driven business insights.

---

## 🎯 Internship Objectives

- Understand logistics and supply chain operations
- Collect and prepare logistics data
- Perform data cleaning and preprocessing
- Calculate important logistics KPIs
- Perform exploratory data analysis
- Create meaningful visualizations
- Identify operational trends and patterns
- Generate business-oriented insights and recommendations

---

# 📊 Key Logistics KPIs

### On-Time Delivery Rate

Measures the percentage of shipments delivered within the expected
delivery time.

### Average Delivery Delay

Measures the average delay experienced across shipments.

### Average Transportation Distance

Measures the average distance travelled by shipments.
